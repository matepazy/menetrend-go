# MÁV service icons

`mav_services.ttf` is the MNR2007 icon font used by the official MÁVPlusz web client.
Downloaded on 2026-10-24 from its configured primary font URL:
https://jegy.mav.hu/PlaceReservationIcons/Graphic/Carriages/fonts/MNR2007.ttf

Service `fontCode` values are Unicode code points in the `MNR2007` character set.
The app preserves the corresponding MÁV descriptions and validity sections.
No icon substitution or assumptions about unreported facilities are made.

The font is a third-party MÁV asset; this attribution does not assert an open-source license.
